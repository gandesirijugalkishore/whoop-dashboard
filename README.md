# WHOOP Dashboard

A beautiful, static WHOOP data dashboard hosted on GitHub Pages. Built by Claude.

## Live App
👉 **https://gandesirijugalkishore.github.io/whoop-dashboard**

## Features
- 📊 Recovery, Strain, Sleep & HRV rings
- 📈 Trend charts (7 / 14 / 30 day range)
- 🏋️ Workout history table
- 😴 Sleep breakdown table
- 🔒 Token stays in your browser — never sent anywhere except WHOOP's API

## How to use
1. Get your WHOOP access token from [developer-dashboard.whoop.com](https://developer-dashboard.whoop.com)
2. Visit the live URL above
3. Paste your token — your data loads instantly

## Stack
- Vanilla HTML / CSS / JS (zero dependencies except Chart.js via CDN)
- GitHub Pages (free hosting)
- WHOOP Developer API v2
